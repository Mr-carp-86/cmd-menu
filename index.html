键盘与操作

  • /聚焦搜索框，输入即筛选命令、作用、场景、标签
  • ↑↓在当前结果里上下移动选中项
  • Enter查看详情（手机上打开底部详情面板）
  • C复制选中命令
  • B把选中命令加入执行清单
  • F收藏 / 取消收藏
  • T切换昼间 / 夜间配色
  • S遇到什么情况？连不上网 / C 盘满 / 权限乱了 / 排查可疑主机…
  • Esc关闭说明、详情面板，或清空搜索

每条命令的详情里都有：语法、带说明的示例、常用参数表（点参数即可复制）、场景分支（想做什么 → 用哪条）、 注意事项与相关命令（点一下跳到那条）。详情顶部可翻「上一条 / 下一条」。
这页是「查阅 + 收集」用的：命令本身不带管理员权限执行，需要真正运行时，用「生成 .bat」导出后右键以管理员身份运行， 或改用同目录的 CMD命令菜单.cmd。
导出的 .bat 打不开？点「生成 .bat」后弹出的另存为窗口会把文件直接写进磁盘，双击即可运行；若浏览器没有 这个窗口（走了下载），文件会被标记成「来自 Internet」，运行时会弹Windows 安全中心 · 无法打开这些文件。此时：
① 右键那个 .bat → 属性 → 底部勾选「解除锁定」 → 确定，再双击；
② 或运行本目录里的 解除锁定.cmd（一键清掉 Desktop / 下载 / 本目录下所有 .bat 的锁定标记）；
③ 或改用控制台版 CMD命令菜单.cmd 的「生成 .bat」——它生成的文件不带这个标记。
标「高危」的命令会在导出时被显著标出，请先逐条确认再做。安全排查与探测这一类（扫描、端口探测、远程执行）只对 自有或已书面授权的主机使用——这些动作都会被目标机的日志与安全软件记录。
